## 📌 About This Repository

This repository contains my solutions to the mandatory HackerRank problems completed as part of the 3rd Semester CSE Problem-Solving Studio Activity.

The problems focus on fundamental programming concepts including:

- Arrays
- Strings
- Matrix traversal
- Dynamic arrays
- Hashing
- Logical problem solving
- Algorithmic efficiency
- Time and space complexity

All solutions are implemented in C and organized into separate folders for clarity.
